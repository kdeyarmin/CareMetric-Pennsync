# Entity Write-Drift Audit — 2026-06-29

Generated by an adversarially-verified sweep of every `base44.entities.<X>.create/update/bulkCreate` write site across `src/` and `base44/functions/` (103 entities, 13 audit batches + per-entity skeptic verification). Each item below is code that **writes a field/enum value the entity schema in `base44/entities/` does not define** — which Base44 silently drops (the failure class the curated `base44/schemaContract.test.js` guards a small subset of).

> **Caveat / how to use this.** This is the *full* auto-discovered set, not a curated allowlist. The repo guardrail intentionally tracks only historically-burned fields. Treat **name-mismatch** items as *likely code bugs* (the code writes a different name than the schema's intended field — adding the field would mask the bug; prefer fixing the write). Treat **simply-missing** items as candidates to add to the schema *after confirming they should persist*. Several entities are written with two incompatible shapes (e.g. AIConfiguration, DocumentSignature) and need a design decision, not a blind add.

**Totals:** 315 missing fields + 13 missing enum values = 328 items across 27 entities; 48 of the fields are name-mismatches (likely code bugs).

## ✅ Resolution status (all 328 resolved additively in this PR)

Every item below has been added to its entity schema, verified by re-checking that all
328 swept fields/enum values now resolve against the schemas, with `test:contracts`
(7/7, incl. Part-1 invariants over all entities) and the build passing. Each fix was
done with reader analysis: where the audit flagged a **name-mismatch**, the readers were
checked and the field was added only when readers actually use the code's name (or the
schema's similarly-named field was unused / belonged to a different entity such as
DocumentPackage). No code renames were required.
